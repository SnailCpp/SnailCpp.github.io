<script type="module">
  import { createApp, ref } from "https://unpkg.com/vue@3/dist/vue.esm-browser.js";

  createApp({
    setup() {
      const message = ref("Hello World!");
      const model = ref("");

      function setMessage(value) {
        message.value = value;
      }

      return { message, model, setMessage };
    },
  }).mount("#app");
</script>

在线预览

代码解析

1. ref 是什么

1

const message = ref("Hello World!");

ref 把普通值包成响应式对象。之后改 message.value，Vue 会重新渲染用到它的 DOM。

2. .value 与模板解包

位置写法
JS 里读写message.value = "新文字"
模板里{{ message }}（不用 .value）

模板会自动「解包」ref，所以按钮里写 setMessage(model) 即可，不用 model.value。

3. 为什么普通变量不会更新

1
2
3
4
5
6

let message = "Hello World!";
return { message };

function setMessage(value) {
  message = value;  // 改了局部变量
}

两个问题：

  1. return { message } 拷贝的是当时的字符串，和后面的 let message 不是同一份绑定
  2. 普通变量不是响应式，Vue 不会在它变化时触发重绘

所以要 const message = ref("...")，修改用 message.value = ...。

4. 函数传参

1

<button @click="setMessage(model)">修改</button>

点击时把输入框当前值传给 setMessage。若写成 @click="setMessage" 不带括号，参数会是事件对象而不是输入文字。

5. v-model 双向绑定

1

<input v-model="model" />
  • 输入框打字 → model 自动更新
  • JS 改 model.value → 输入框显示跟着变

等价于：

1

<input :value="model" @input="model = $event.target.value" />

CDN 根组件里用 const model = ref('') 即可；defineModel() 只在 .vue 子组件的 <script setup> 里用。
