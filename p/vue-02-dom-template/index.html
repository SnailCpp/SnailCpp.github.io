Vue 学习 02：DOM 根组件模板

CDN 不写 template 选项时，Vue 如何把 #app 里的 HTML 当作根组件模板编译、挂载，以及和 Vite 工程的区别。

本节目标

  • 理解「模板」可以写在 HTML 里，而不只在 JS 或 .vue 文件里
  • 知道 mount('#app') 时 Vue 会读取容器的 innerHTML
  • 区分 DOM 内模板与 Vite 工程里 <template> 的用法

官方说法

当根组件没有设置 template 选项时，Vue 将自动使用挂载容器的 innerHTML 作为模板。

这句话的意思是：#app 里面已有的 HTML（含 {{ }}、@click）就是根组件的视图模板。

<script type="module">
  import { createApp, ref } from "https://unpkg.com/vue@3/dist/vue.esm-browser.js";

  createApp({
    setup() {
      const count = ref(0);
      return { count };
    },
  }).mount("#app");
</script>

Vue 发现没有 template，就把 #app 的 innerHTML 当模板编译，再绑定 setup 返回的数据。

挂载前 DOM
┌─────────────────────────────┐
│ <div id="app">              │
│   <button @click="count++"> │
│     {{ count }}     │
│   </button>                 │
│ </div>                      │
└─────────────────────────────┘
        │
        │  createApp({...}).mount('#app')
        ▼
1. 读取 #app 内的 HTML
2. 当作模板编译（识别 {{ }}、@click 等）
3. 绑定 setup / data 里的 count
4. 接管 #app 并渲染

编译用的是挂载前的 innerHTML；mount 之后由 Vue 接管 #app 内部。

为什么 CDN 常用这种写法

  • 无构建：一个 index.html + <script type="module"> 即可，不需要 Vite/Webpack
  • HTML 和 JS 分工：结构在 HTML，逻辑在 setup()
  • 服务端也可配合：后端先输出 #app 里的 HTML，前端再 mount

以后用 Vite 时，模板主要在 .vue 的 <template> 里，一般不再把模板写在 index.html 的 #app 中。
