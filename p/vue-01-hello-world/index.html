认识 Vue

Vue 是一款用于构建用户界面的 JavaScript 框架。它基于标准 HTML、CSS 和 JavaScript 构建，并提供了一套声明式的、组件化的编程模型，帮助开发者高效地开发用户界面。

本节目标

  • 用 CDN 方式创建第一个 Vue 3 应用
  • 理解 createApp、setup、mount 的作用
  • 知道为什么 HTML 里写 {{ message }} 需要 Vue 处理
  • 用 v-cloak 避免挂载前闪烁

代码解析

1. 模板

1

<div id="app" v-cloak>{{ message }}</div>

原生 HTML/JavaScript 不认识 {{ }}，浏览器把 {{ message }} 当作普通文本, 未引入 Vue 时会直接显示 {{ message }}。只有 Vue 挂载并编译模板后，才会显示实际内容。

2. 入口脚本

1
2
3

import { createApp } from "https://unpkg.com/vue@3/dist/vue.esm-browser.js";
createApp({
  setup() {
    return {
      message: "Hello World!",
    };
  },
}).mount("#app");

这段代码的作用是改变 HTML 的显示内容，把 {{ message }} 变成 Hello World!。

  • 引入的是 vue.esm-browser.js是 Vue 的完整版（带编译器的）, 用于编译模板。
  • createApp 创建一个 Vue 应用，并返回一个对象，这个对象有一个 mount 方法，用于挂载应用。
  • setup 函数用于定义组件的逻辑，返回一个对象，这个对象有一个 message 属性，用于定义组件的 data。这个 message 属性会在模板中被渲染。
  • mount 方法用于挂载应用，将应用挂载到 HTML 的 #app 元素上。

Vue 在浏览器里把 {{ message }} 编译成 render 函数，然后执行 render 函数，再渲染到页面。编译过程如下：

1

{{ message }} → 编译（一次）→ render 函数 → 执行 → 更新 DOM

3. HTML 显示 vs JS 执行

预览页面时，在 CDN 环境或者网络环境较差时，用户可能会先看到 {{ message }}，然后看到 Hello World!。这是因为浏览器会按顺序先解析 HTML 标签，然后解析 <script> 标签的的 JS 代码。因此，为了用户体验，我们可以使用 v-cloak 属性来避免闪烁。

4. v-cloak 避免闪烁

v-cloak 属性用于在 Vue 挂载前隐藏元素，避免在 Vue 挂载前用户看到 {{ message }}。
